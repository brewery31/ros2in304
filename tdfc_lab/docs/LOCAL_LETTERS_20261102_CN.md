# 字母恢复统一局部控制器：2026-11-02

用户明确要求字母也使用我们的算法，不采用集中式分配。本次修改基于63ff2a2，移除了字母的 Hungarian 分配和固定关键点跟踪。

## 实现

所有七种成形场景统一调用 SceneController → CandidateController → 每个ego的CurveEgoInterface → curve_acceleration → ORCA → DirectionalGovernor。各ego只输出自己的动作，不交换邻居意图或候选动作。公共目标形状在开始前给定，邻居作用按可见距离筛选。仿真仍由一台主机调度，这不是机载多进程部署或真实局部传感验证。

R/A/L目标改为完整笔画图，A横杠与R分叉独立定义，不把抬笔处连接为假斜线。总笔画长度与圆环/螺旋线同用0.7N规则，五机字母总长3.5m。它不是五个给机器人分配的目标：R图有6个顶点、L图有3个顶点，均由4096个控制点表示。评价按笔画弧长加权采样。

保留原贴合、配对、密度重分配、阻尼、ORCA与governor参数。只扩展目标几何和叶端点元数据处理；没有用字母ID指定站位，也没有给每架设置固定成形目标。返航阶段各机回自己的初始起降柱，没有任何匹配。

这是原算法的曲线/笔画适配版。尖角与分叉处切向不唯一，未证明完整闭环收敛；不能把光滑曲线的分析直接套到字母图。

## 当前验证结果

24项unittest通过，包括三个历史曲线回放、字母也调用同一名义控制器、无集中匹配导入、不可见邻居变化不影响ego输出、机器人顺序变换不改变动作、笔画弧长权重与叶端点检查。

统一参数下完成七种组合×三个固定种子×60s，共21次速度环数值仿真。圆环与螺旋线共12/12达到末段持续成形标准；**五机字母0/9达到标准**。21/21均没有间距低于0.5m，整体步内距离下界最小0.579900m。安全阈值与成形效果分开记录，不能因没有碰撞就说字母形成成功。

## 旧结果处理

上一版R/A/L的9次成功属于集中式初始匹配的固定目标方法，不能作为本文算法结果。混合的21/21成功结论已撤回。旧数据未删除，原目录加了警示。由于目标几何也由五关键点变成完整笔画，本轮与旧数据不能用作“只去掉匹配”的因果对照。

后续应在同一局部控制框架内研究尖角/分叉附近的作用分工、平衡点与稀疏规模限制；本轮没有用另一种控制器替代失败，也未继续改增益直到通过。
