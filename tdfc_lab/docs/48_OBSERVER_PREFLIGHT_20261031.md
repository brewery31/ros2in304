# 八机因果观测处理：协议、证明范围与验证

## 改什么、保持什么

上一轮8cm余量在216次验证中没有碰撞，但只有111次联合达标。此次不再调余量、控制增益、目标几何、初始化或质量门槛；只研究观测处理，优先螺旋线与圆环N=8。

新模块`stfc/observation_filter.py`只接收观测位置/速度、测量/决策时间戳及已知速度上限。初始估计来自首帧观测；后续按ID保留状态，重复时间戳不再次融合。没有目标形状投影、真实位置、其他机器人的控制命令或未来观测输入。固定ID顺序及同步、共享的每个体观测模型仍是仿真假设，不是完整异步机载感知。

研究入口为任务级`observation_processor`，必须显式声明`research_mode=observation_stress`，只接入曲线研究路径，默认关闭。名义控制、ORCA及停车层统一使用估计位置/速度；原有内环仍使用本机即时速度，未宣称消除这一已有理想化假设。真实位置仅用于仿真积分、审计及误差日志，误差日志不反馈动作。

即使原始观测没有噪声，处理后的观测也不继承准确观测停车证书；行级`certificate_applicable`和`governor_proof_observation_scope`均为False。

## 因果递推

在测量时刻t_k收到z_k、w_k。先将观测速度投影到已知速度球，记为w_k^c。设h_k=t_k−t_(k−1)，平滑常数T_f≥0，α_k=1−exp(−h_k/T_f)；T_f=0时α_k=1。

\[
\hat p_k^- = \hat p_{k-1}+h_k\hat v_{k-1},\qquad
\hat p_k = (1-\alpha_k)\hat p_k^-+\alpha_k z_k,
\]
\[
\hat v_k=(1-\alpha_k)\hat v_{k-1}+\alpha_k w_k^c,\qquad
\hat p(t)=\hat p_k+(t-t_k)\hat v_k.
\]

零平滑常数候选是观测速度裁剪加时间戳外推，并非与原始输入完全等价的单一延迟开关。所有候选都从首帧开始执行，没有跳过初始化瞬态。重复旧帧只外推，不当作新独立观测再次平均。

## 能证明哪些性质

**因果性与信息接口。** 递推只依赖历史状态和当前已收到的观测；构造和单元测试同时检查无未来观测输入、数组不共享内存、时间戳及控制/ORCA/停车层实际入参。真实位置误差日志开关前后轨迹逐元素相同。

**理想常速无噪声的预测一致性。** 若首帧准确、真实速度恒定且不超过速度上限，归纳可得每个测量时刻的估计位置/速度准确；外推到决策时刻也准确。这不是加速运动或有噪声时的精确性保证。

**静止条件下的降噪。** 固定采样h、真实速度为零且观测速度准确为零、位置噪声为独立同分布零均值单坐标方差σ²时，位置误差满足e_k=(1−α)e_(k−1)+αη_k。稳态方差为：

\[
\operatorname{Var}(e)=\frac{\alpha}{2-\alpha}\sigma^2.
\]

推导是对上述独立递推取方差并求固定点；初值项以(1−α)^(2k)衰减。该结论不能直接用于运动中、相关噪声或速度也带噪的情况；实际实验另报RMSE与最大误差。

**有界误差和加速度下的误差递推。** 若测量位置/速度范数误差分别≤ε_p、ε_v，真实速度位于速度球内、加速度范数≤a，测量时刻位置/速度估计误差上界为E_p,k、E_v,k，则：

\[
E_{v,k}\le(1-\alpha_k)(E_{v,k-1}+ah_k)+\alpha_k\varepsilon_v,
\]
\[
E_{p,k}\le(1-\alpha_k)(E_{p,k-1}+h_kE_{v,k-1}+\tfrac12 ah_k^2)+\alpha_k\varepsilon_p.
\]

理由：速度球凸投影对球内真值不增加误差；常速度位置预测的真实加速度余项至多ah_k²/2，速度变化至多ah_k；分别使用三角不等式。首帧误差界为E_p,0≤ε_p、E_v,0≤ε_v。外推信息年龄A后，位置误差再增加至多AE_v,k+aA²/2。

这说明平滑虽可降低特定随机模型下的方差，也会引入运动偏差；不能把滤波后的标准差当确定性安全界。本轮高斯噪声没有固定ε_p/ε_v，上式只能在明确的误差有界事件内解释。

**尚未证明：** 带估计误差的持久分离平面一致性、完整停车可行集不变性、完整闭环收敛、任意初始化形成或真实飞机安全。没有用这些局部性质替代完整安全定理。

## 预先冻结的开发与独立验证

- 固定上一轮8cm余量及端点修正后的控制算法。
- 候选：原始观测、仅速度裁剪/时间戳外推，以及平滑常数40/100/200ms的因果CV处理。
- 开发240次：2形状×2初态×2执行滞后×2种子1700–1701×3观测条件×5候选；条件为准确、20mm位置噪声、组合噪声/80ms感知延迟。
- 选择顺序：碰撞数最少、无碰撞联合达标数最多、无碰撞末态达标数最多、最后按预定候选顺序；原始输入可被选为回退。
- 冻结选择后，使用1800–1802新种子独立验证432次：2形状×3初态×3执行滞后×3种子×4观测条件×2配置。新增40ms纯感知延迟条件，不按新数据重新选择参数。
- 每次60s、dt20ms；物理速度/加速度限制及全程距离审计不变；双方初态、目标/评价点池和外生噪声逐例配对。全部失败保留。
- 同时报碰撞、覆盖、贴合、联合达标、停车/可行性计数、原始和处理后位置误差RMSE/最大值。误差由仿真真值诊断，不参与估计器或参数在线调整。

原始观测路径已与上一轮封存源码对照六个短案例：全部保存的初末态、完整轨迹、命令、覆盖曲线及审计数组逐元素相同。新模块的有效性与噪声条件下的安全仍需本轮独立数据回答。

## 独立验证结果

240次开发全部完成。冻结规则选择“速度观测裁剪＋时间戳外推”，平滑常数为0；不是宣称所有低通平滑均有益。开发集无碰撞联合达标23/48→27/48，原始输入和选定配置都没有碰撞。

432次新种子验证也全部完成，每个条件/配置54次，均采用同一8cm余量：

| 观测条件 | 原始输入联合达标 | 时间戳外推联合达标 | 两侧碰撞 |
|---|---:|---:|---:|
| 准确即时观测 | 47/54 | 47/54 | 0 / 0 |
| 20mm位置噪声 | 13/54 | 13/54 | 0 / 0 |
| 40ms感知延迟 | 25/54 | 45/54 | 0 / 0 |
| 组合噪声与80ms延迟 | 22/54 | 34/54 | 0 / 0 |

总体联合达标107/216→139/216，两侧均没有碰撞。该提升来自本批配对，不能把不同种子的上一轮111/216作为其直接对照。未在新数据上重新选择参数。

本轮解决了一部分信息滞后造成的性能损失，**没有解决单独位置噪声下的形成质量**，也没有证明鲁棒安全。默认路径不启用预处理。后续需要单独研究位置平滑与速度估计的分工、停车约束对测量误差的响应，并结合真实定位标定；不能把本批新种子继续当开发集后仍称为独立测试。
